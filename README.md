# 🌏 全球市场盘前日报 — Claude Cowork Skill

亚洲每个工作日早上自动搜索财经新闻，生成一份覆盖美股、美债、大宗商品、黄金、原油、汇率的结构化盘前简报，辅助亚洲市场投资判断。

**报告语言：中文 | 运行时间：周二至周六 09:40 JST | 适用平台：Claude Cowork**

→ [查看示例报告](example/market_briefing_sample.md)

---

## 设计理念：新闻优先

这个 Skill 不直接调用行情 API，而是从财经新闻中提取记者已经核实的数字，再结构化成报告。

好处：不依赖行情接口权限，数据主要从新闻来源追溯，简化构建获取最新信息。
代价：某个标的当天没有新闻报道，该行就不会出现在报告里（不写"暂缺"，直接跳过）。

---

## 使用方式

### 方式一：Claude Cowork（推荐，支持定时自动运行）

1. 将 `SKILL.md` 复制到 Cowork 的 skills 目录（通常是 `.claude/skills/market-briefing/SKILL.md`）
2. 重启 Cowork 或重新加载 skills
3. 对 Claude 说：**"生成市场日报"** 或 **"market briefing"** 即可触发

报告自动保存到 workspace 下的 `market-briefing-result/` 文件夹。

设置定时自动运行：在 Cowork 中创建 Scheduled Task，时间设为周二至周六 09:40 JST（cron: `40 9 * * 2-6`，时区 Asia/Tokyo），指令填 `Run the market-briefing skill and save the report`。

### 方式二：任意 Claude 界面（手动触发）

不使用 Cowork 的话，直接将 `prompt.md` 的内容粘贴到任何 Claude 对话窗口（claude.ai 网页版、手机 App 等）即可生成一份报告。无需安装，无需配置。

## 报告结构（4 个板块）

| 板块 | 内容 |
|------|------|
| 🌐 主线叙事 | 昨夜市场最核心的一条因果链，2–3句话。检测到跨资产信号时直接点名（如"形成X01避险格局"）。|
| 📰 昨夜发生了什么 | 5个子模块：美股整体 · 债券/黄金/能源 · 具体事件与催化剂 · 地缘与战争 · 亚洲相关。有大幅异动的标的内嵌⚠️一行说明。|
| 📊 数据速览 | 仅展示新闻中出现过具体数字的标的，无数据直接跳过。|
| 📋 市场总评 & 亚洲关注 | 纯前瞻分析，不复读前三板块的内容。给出当前市场阶段判断 + 日经/港股/A股今日开盘展望。|

## 自定义

**关键价位**（用于⚠️预警提示，在 SKILL.md Panel 2 中修改，改成自己的持仓位置）：
仅供参考
```
VOO: $545(-15%), $513(-20%) | QQQ: $541(-15%), $510(-20%), $478(-25%)
SMH: $342(-20%), $321(-25%), $300(-30%) | TLT: $85, $80, $75
```

**覆盖标的**：默认跟踪美股（VOO/QQQ/NVDA/GOOGL/MSFT/SMH/EWY/SCHD）、美债（TLT/SHY/EDV）、大宗商品（黄金/原油）、汇率（USD/JPY、USD/CNY）。在 SKILL.md Panel 3 中可以增减。

**语言**：报告模板为中文。如需其他语言，替换 SKILL.md Step 3 中各 Panel 的 header 和示例文本即可。

## 背景

这个 Skill 的出发点是：想每天看一份结构化的全球市场简报，但不想注册一堆数据接口、不想维护 API key、也不想写代码。

新闻优先的方案解决了这个问题——只需要 Claude 和搜索权限，零配置就能跑起来。代价是数据完整性弱于直接拉行情，但对于"快速掌握昨夜发生了什么"这个目标来说已经足够。

后续计划构建一个生产版本：接入 YFinance / AkShare 等数据源，通过 GitHub Actions 定时运行，实现精确行情数据 + AI 分析 + 飞书推送的完整链路。
